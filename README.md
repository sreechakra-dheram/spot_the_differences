# 🕵️ Spot the Difference - JSON Configurable Game

A fun and interactive **“Spot the Difference”** game built using **HTML, CSS, and JavaScript**, driven entirely by a **JSON configuration**. Just update the JSON file to load different image sets and difference zones — no code change required!

## 🔥 Features

- 🔍 Two images displayed side-by-side
- ✅ Click to spot and highlight differences
- 🎯 Real-time score tracking
- 🏁 Success message when all differences are found
- ⏱️ Timer to track completion time
- 🔊 Sound effects on correct clicks and game completion
- 📱 Fully responsive for desktop and mobile
- 🧩 Easily configurable via JSON
